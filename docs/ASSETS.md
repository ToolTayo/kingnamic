# Asset provenance

All world graphics, interface symbols, crest, and procedural audio in this repository are original programmatic work created for KINGNAMIC. They require no third-party asset downloads. System serif/sans-serif fonts are used. No reference-game assets, branded characters, or copied layouts are included. Names and branding are provisional and have not received trademark clearance.

Runtime dependencies: Phaser 3 and EventEmitter3 (MIT). Their complete copyright and license notices are included in `public/THIRD_PARTY_NOTICES.txt` and copied into the production output. Development dependencies retain their respective upstream licenses in node_modules; the package lock records exact versions.
